# Architecture\n\n`agent_loop_mini` is a single-module library designed for deterministic, bounded tool execution.\n\n## Core Components\n\n1. **`LLMPort` Protocol**: An interface requiring `complete(messages, *, max_tokens) -> str`.\n2. **Test Doubles**: `RecordedLLM` and `FakeLLM` enable deterministic unit testing without external calls. They track all requests in `calls` attributes.\n3. **`Tool` & `Budget`**: Immutable configuration dataclasses that enforce input validation and runtime constraints before the loop starts.\n4. **Execution Loop (`run_agent`)**: A procedural loop that enforces terminal conditions in strict order: deadline check, step count check, context size check, LLM completion, reply parsing, and tool execution (with error/invalid reply handling).\n
