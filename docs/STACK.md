# Stack\n\n## Used\n\n| Tool | Why |\n|---|---|\n| Python >= 3.10 | Baseline for modern typing features. |\n| uv | Unified dependency and build management. |\n| hatchling | Minimalistic, standards-compliant build backend. |\n| ruff | High-performance linting and formatting. |\n| mypy (strict) | Static type safety; project provides `py.typed`. |\n| pytest + pytest-cov | Standards-compliant testing and coverage. |\n| gitleaks | Prevention of secret leakage. |\n| GitHub Actions | CI automation. |\n\n## Discarded\n\n| Tool | Why not |\n|---|---|\n| Poetry | Slower dependency resolution; uv handles all requirements. |\n| black/isort | Consolidated into ruff. |\n| tox/nox | Handled via CI pipeline and simple scripts. |\n
