# Security Model\n\n## Defended Threats\n\n1. **XML Tag Injection**: Untrusted tools returning `</tool_result>` could potentially disrupt the communication protocol. The library escapes all tool results by transforming `</tool_result>` into `&lt;/tool_result&gt;`.\n2. **Runaway Resource Consumption**: Models or prompts can cycle infinitely. We enforce hard caps on `max_steps`, `max_seconds`, `max_consecutive_errors`, and `max_context_chars`.\n3. **Event Leaks**: Monitoring callbacks (`on_event`) are restricted to structural metadata (step number, tool name, outcome, duration) to prevent accidental leakage of tool payloads or user data.\n4. **Loop Detection**: We detect repeated `(tool, args)` pairs to stop circular reasoning chains.\n\n## Not Defended\n\n- Arbitrary Code Execution: The agent loop executes any Python `fn` provided in the `Tool` definition. Ensure tools provided are safe.\n
