# agent-loop-mini\n\nMinimal tool-using agent loop over any text-completion LLM. It focuses on deterministic execution with strict resource budgets (time, steps, context), loop detection, and secure tool output handling.\n\n## Installation\n\n```bash\npip install agent-loop-mini\n```\n\n## Usage\n\n```python\nfrom agent_loop_mini import Budget, RecordedLLM, Tool, run_agent\n\nadd = Tool("add", "Add two integers", lambda a, b: a + b, {"a": "int", "b": "int"})\nllm = RecordedLLM(['{"tool": "add", "args": {"a": 2, "b": 3}}', '{"final": "5"}'])\nresult = run_agent(llm, "Add 2 and 3", [add], budget=Budget(max_steps=5))\nprint(result.status, result.final)\n```\n\n## API Summary\n\n- **`Tool(name, description, fn, params)`**: Defines an executable tool. Name must match `^[a-z][a-z0-9_]{0,63}$`. Parameter types supported: `str`, `int`, `float`, `bool`.\n- **`Budget(...)`**: Configuration for execution limits: `max_steps`, `max_seconds`, `max_context_chars`, `max_consecutive_errors`, `max_invalid_replies`, `max_result_chars`, `max_tokens`. All must be >= 1.\n- **`run_agent(...)`**: The main execution loop. Accepts `LLMPort` and `tools` sequence. Returns `AgentResult`.\n- **`render_system_prompt(tools)`**: Returns the system prompt describing tools and the JSON communication protocol.\n- **`AgentResult(...)`**: Contains `status` (final, max_steps, deadline, loop_detected, tool_errors, invalid_replies, context_exhausted), `final` result string, and a `steps` history tuple.\n\n## Why not LangChain or smolagents?\n\nThese frameworks often hide the control loop, creating implicit state and dependency bloat. `agent-loop-mini` provides a transparent, dependency-free Python function that forces explicit budgeting and terminates with a deterministic status.\n\n[Security details](docs/SECURITY.md)
